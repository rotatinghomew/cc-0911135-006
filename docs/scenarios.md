# 业务演练

|情景|原文或规则|应发布或隔离的内容|
|---|---|---|
|合并表头|两行表头及 rowspan/colspan|Ni/结果 与 Ni/单位 分别归属正确|
|测量语义|<0.02、0、空白、撤回|四种不同含义，不混入脚注检测值|
|非法跨度|layout=badspan|阻断整个表，保留结构错误定位|
|字段缺失|layout=missing|不能发布缺单位的记录|
|行单位冲突|layout=unit-conflict|歧义行进入隔离，不默认为目标单位|
|规则冲突|同表命中互斥规则|不任取第一个，结果有规则证据|
|离线重提取|接收后停止源站，换规则版本|只用保存字节重提取，两版结果分别保留|
|字符解码|encoding=windows-1252|µ 正确解码，保存原字节与解码依据|
